Kleintierzuchtverein Marbach
Über das Projekt

Diese Website ist der Internetauftritt des Kleintierzuchtvereins Marbach. Sie dient dazu, den Verein vorzustellen und Besuchern einen Überblick über den Verein, seine Aktivitäten und seine Arbeit in der Kleintierzucht zu geben.

Ziel der Website ist es, Informationen übersichtlich bereitzustellen und Interessierten einen einfachen Zugang zum Verein zu ermöglichen.

Funktionen

Die Website ist als zentrale Informationsplattform für den Verein gedacht. Je nach aktuellem Entwicklungsstand umfasst sie unter anderem folgende Bereiche:

Informationen über den Verein
Vorstellung der Kleintierzucht und der Vereinsarbeit
Aktuelle Informationen und Veranstaltungen
Bilder und Einblicke in das Vereinsleben
Kontaktmöglichkeiten für Interessierte
Technologien

Für die Entwicklung werden Webtechnologien wie HTML, CSS und JavaScript verwendet, sofern diese im jeweiligen Projektbereich eingesetzt werden.

Lokale Entwicklung

Um die Website lokal aufzurufen, kann ein einfacher HTTP-Server verwendet werden.

Voraussetzung ist, dass Node.js und npm installiert sind.

Repository herunterladen oder klonen.
Den Projektordner in Visual Studio Code öffnen.
Das Terminal im Projektverzeichnis starten.
Folgenden Befehl ausführen:
bash
npx --yes http-server .


Anschließend wird im Terminal die lokale Adresse angezeigt, unter der die Website erreichbar ist. In der Regel ist dies:

text
http://127.0.0.1:8080


Zum Beenden des Servers Strg + C im Terminal drücken.

Projektstruktur

Die genaue Ordnerstruktur richtet sich nach dem aktuellen Stand des Projekts. Die HTML-Dateien bilden die Grundlage der Website, während CSS für die Gestaltung und JavaScript für interaktive Funktionen eingesetzt werden kann.

Veröffentlichung

Der Quellcode wird über GitHub verwaltet. Die Website kann bei entsprechender Konfiguration beispielsweise über GitHub Pages veröffentlicht werden.

Weiterentwicklung

Die Website wird bei Bedarf erweitert und überarbeitet. Ziel ist es, die Inhalte aktuell zu halten und die Bedienbarkeit sowie die Darstellung auf verschiedenen Geräten kontinuierlich zu verbessern.
